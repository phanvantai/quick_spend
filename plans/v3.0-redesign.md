# QuickSpend v3.0 — App Intents-first Redesign

Status snapshot — **6 of 7 phases shipped on `develop` branch**. Resume from
Phase 7 below.

---

## Goal

Lift QuickSpend to a Siri-first product where the primary path is
"Hey Siri, add expense …" without opening the app. The on-screen UI exists
to view/edit data, not to be the main capture surface — so it gets
dramatically simpler, with denser, more consistent motion.

## Decisions locked at planning time

| Decision | Choice |
|---|---|
| Voice FAB inside the app | Keep as fallback, extract `VoiceCaptureViewModel` to remove the god-object |
| Tab structure | **2 tabs** (Home, Transactions). Settings + Add Manual = toolbar icons. FAB stays bottom-right |
| Home dashboard | Balance + summary + **1 focal chart with toggle**. Donut + Bar only — Line chart deferred |
| Design system | **Full refresh tokens + typography + motion**, palette unchanged |
| AppBar style | Native large title + ToolbarItem (no custom AppBar component) |
| Settings presentation | Sheet with `.large` detent, grab handle, Done button |
| Line chart | Deferred — `TrendsSection.swift` + `MonthlyBarChart.swift` kept as orphaned but unwired |

## Architectural notes for the resume session

### VoiceCaptureViewModel pattern
The view model is `@Observable @MainActor` with two inits — `convenience init()` for production and full DI init for tests. Same pattern works for any future view-model extraction (avoid default arg expressions on services that are MainActor-isolated).

### ModalTemplate pattern
For any future full-screen modal, pass a custom `hero` ViewBuilder + content
and `ModalCTA` for buttons. `ModalGradientHero(icon:gradient:glowColor:animatedSymbol:)`
is the shorthand for SF-symbol-based heroes; bespoke heroes (e.g.
`WhatsNewBalanceModal` previewing the real `BalanceHero`) supply their own.

### Typography vs raw .font(...)
New code should default to `Typography.body` / `Typography.headline` etc.
The token file is at [QuickSpend/Theme/Typography.swift](../QuickSpend/Theme/Typography.swift). Acceptable to use `.monospacedDigit()` modifier on a Typography token (see `Typography.monoHeadline`).

### AppConfig forward-compat
Every new `AppConfig` field MUST be added to the custom `init(from:)` decoder with `decodeIfPresent ?? default`. Existing pattern is in [Models/AppConfig.swift](../QuickSpend/Models/AppConfig.swift). Unit-test the forward-compat path (decoding old JSON without the new field) — see `AppConfigTests.swift`.

### Synchronized file groups
The Xcode project uses `PBXFileSystemSynchronizedRootGroup` — Swift files added under existing folders auto-discover, no `.pbxproj` edits needed. Confirmed working through Phases 1–5.
